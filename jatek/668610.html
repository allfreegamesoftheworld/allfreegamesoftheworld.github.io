Röviden a játékról

Lords of War is a fast-paced strategic card game that supports real-time PvP battles. Although game design may resemble turn-based TCG/CCG games, game mechanics is more like a real-time 3D card-based roleplaying game – this combination provides an entirely new gaming experience.
