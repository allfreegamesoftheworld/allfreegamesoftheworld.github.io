Minimális gépigény

Minimum:
  • Requires a 64-bit processor and operating system
  • OS: Windows 10 64-bit, version 21H1 (build 19043) or newer
  • Processor: Any 64-bit x86 CPU with SSE2. Dual core, 2.0 GHz.
  • Memory: 8 GB RAM
  • Graphics: Any discrete GPU, or integrated graphics from 2020 or later (Intel Iris Xe, AMD Radeon Vega or newer). Recommended if you run your desktop at 1440p or 4K.
  • DirectX: Version 11
  • Additional Notes: Patchy runs as a transparent, always-on-top overlay that sits on your taskbar, using Windows desktop compositing. It is Windows only. Clicks pass through to your desktop everywhere except the game's own buttons. It draws at your desktop resolution, so higher resolutions ask more of your graphics card. On lower-end PCs, Settings lets you turn shadows off and switch edges to Compatible. The game steps aside automatically while a fullscreen game or video is in front. Use the tray icon to move it to another monitor. An internet connection is only needed for the optional live weather, which uses the city you type into Settings.
