Röviden a játékról

This is an application software for 3D desktop pets. It supports importing  most 3D format models, such as (VRM/FBX/OBJ/glTF2, etc.). Currently, users can only upload VRM files to support various basic actions, motion capture and cloning movements from uploaded videos.
