Röviden a játékról

Gravity is a platformer/obstacle game where your only tool is to use a gravitational field to guide an astronaut through space. With a custom built physics engine, pull him through each level, dodging asteroids and other harmful space objects along the way.

Minimális gépigény

Minimum:
  • OS: Windows 10 64-bit
  • Processor: Intel Core i3-6100 / i5-4590 or AMD Ryzen 3 1200
  • Memory: 1 GB RAM
  • Graphics: NVIDIA GTX 750 Ti / AMD Radeon R7 360
  • Storage: 1 GB available space
  • Additional Notes: The game can actually run with much less disk space (~0.2 GB), but Steam does not allow periods in the text box so the number has been rounded up.
