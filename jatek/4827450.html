Minimális gépigény

Minimum:
  • OS: Windows 10 64-bit
  • Processor: Dual core 2.0 GHz (Intel Core i3 / AMD Ryzen 3 or better)
  • Memory: 4096 MB RAM
  • Graphics: Integrated graphics (Intel UHD / AMD Radeon), no dedicated GPU needed
  • Network: Broadband Internet connection
  • Storage: 4096 MB available space
  • Sound Card: Any Windows compatible device
  • Additional Notes: Hire uses AI for its live character conversations and generated portraits, connecting to your own ChatGPT account (it uses your existing ChatGPT plan, with no separate purchase). A broadband internet connection is recommended for these features; the game also ships with a bundled offline art pack.
