Minimális gépigény

Minimum:
  • Requires a 64-bit processor and operating system
  • OS: Windows 10
  • Processor: Intel core i5 / AMD Ryzen 5 or equivalent
  • Memory: 16 GB RAM
  • Graphics: NVIDIA GeForce GTX 1650 Super or equivalent
  • DirectX: Version 11
  • Storage: 2 GB available space
  • Sound Card: DirectX compatible sound card
  • VR Support: Meta Quest 2 via Link, using OpenXR
  • Additional Notes: PC VR game using OpenXR. Meta Quest 2 via Link cable has been tested. Other OpenXR-compatible headsets may work but have not been tested.
