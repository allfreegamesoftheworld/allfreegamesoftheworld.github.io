Tartalmi figyelmeztetés

The game features mild blood effects and large blood stains when players are eliminated. There is no gore; the blood effects are not fully realistic. The visual style is not hyper-realistic. Mature content is presented in a comical, and unserious manner. The game contains frequent strong language, appearing in 60% of voice lines. The main map is set in an abandoned school building that has been unused for years. This setting has no correlation to real-life tragedies. We do not endorse such disgraceful acts in any way. Neither the game nor we have any association with such events.
