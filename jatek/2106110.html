Tartalmi figyelmeztetés

The game is set in a Mafia world and makes allusions to underworld businesses and behaviors: prohibited substances, alcohol, extortion, violence, threats and non-explicit sexual themes. Language used includes light profanity. Cartoon violence is included but is designed not to be graphic. (these is some blood and pain depicted but it is muted. The game is game does not include death (NPCs and player characters can only ever be stunned). There is no explicit nudity (pixelation is used in cases where it would occur).
