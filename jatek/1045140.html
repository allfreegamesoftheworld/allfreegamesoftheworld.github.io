Minimum:
  • Requires a 64-bit processor and operating system
  • OS *: Windows 7 SP1, Windows 8.1, Windows 10
  • Processor: Intel Core i5-4590 / AMD FX 8350
  • Memory: 4 GB RAM
  • Graphics: NVIDIA GeForce GTX 970 / AMD Radeon R9 290
  • Storage: 4 GB available space
  • VR Support: SteamVR. Room Scale 2m by 1.5m area required
  • Additional Notes: There are well known issues with SteamLink and Meta Quest controllers. For a stable experience, use Meta Horizon Link instead of SteamLink with this game.
