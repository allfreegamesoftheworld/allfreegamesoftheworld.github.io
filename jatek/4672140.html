Minimális gépigény

Minimum:
  • Requires a 64-bit processor and operating system
  • OS: Windows 10/11 (64-bit)
  • Processor: Any x86-64 CPU with SSE2
  • Memory: 1 GB RAM
  • Graphics: Any GPU with a working WDDM driver
  • DirectX: Version 11
  • Network: Broadband Internet connection
  • Storage: 200 MB available space
  • Additional Notes: x64 only — ARM64 runs via emulation. No VC++ Redist install required.
