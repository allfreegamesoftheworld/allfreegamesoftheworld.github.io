Tartalmi figyelmeztetés

The game contains stylized violence (combat against enemies). It also includes alcohol use: an “alcohol bottle” item that triggers a brief intoxication effect (screen wobble/distortion). Additionally, the game features a scratch-off ticket with a random outcome (simulated gambling-like mechanics). The game does not contain sexual content or nudity.
