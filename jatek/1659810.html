Röviden a játékról

Figurine Scene Simulator is a sandbox game where you build a character portfolio from a huge library of figurines. You can place the figurines in scenes and set them to animations to compose artistic expressions and take screen and video captures. You can also expand your character options via DLC.

Tartalmi figyelmeztetés

Figurine Scene Simulator is meant to be a complete game which can be enjoyed without the use of NSFW type content. However, there is also a fair amount of NSFW type costumes and nudity*. This content will grow during development. In addition to some horror/gory figurines and scenes, additional fx will be added to allow for extremely violent/gory scenes. *Notes: By default, NSFW/Nudity is turned off, it's enabled in-game through settings. FSS is not intended to be a sex simulator, though it ranges per artist, the type of nudity is generally more "doll" like than realistic. While some is available in the base game, most nudity is unlocked through the Premium Character Creator DLC which allows you to turn on/off clothes components on a lot of figurines. All Characters are 18 or older.
