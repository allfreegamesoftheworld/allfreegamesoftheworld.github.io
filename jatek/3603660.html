Minimum:
  • Requires a 64-bit processor and operating system
  • OS: Windows 10 version 21H1 (build 19043) or newer
  • Processor: x86, x64 architecture with SSE2 instruction set support, ARM64
  • Graphics: DX10, DX11, DX12 or Vulkan capable GPUs
  • Additional Notes: Hardware vendor officially supported drivers For development: IL2CPP scripting backend requires Visual Studio 2019 with C++ Tools component or later and Windows SDK version 10.0.19041.0 or newer
