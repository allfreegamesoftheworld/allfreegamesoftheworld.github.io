Röviden a játékról

SaGaS is a project based on new Chinese grotesque Cthulhu theme, integrating the old Hong Kong retro style and background settings of the 20th century. It is a fan project based on Scara-Ei character shipping from Genshin Impact. The game uses puzzles and maze solving as its main gameplay.
