Minimális gépigény

Minimum:
  • Requires a 64-bit processor and operating system
  • OS: Windows 10 64-bit
  • Processor: Intel Core i5 / AMD Ryzen 3 or equivalent
  • Memory: 8000 MB RAM
  • Graphics: NVIDIA GeForce GTX 1060 (6GB VRAM) / AMD Radeon RX 580
  • DirectX: Version 11
  • Storage: 5000 MB available space
  • Sound Card: DirectX compatible
  • Additional Notes: SSD is highly recommended. The game uses local AI generation for cards, which requires significant GPU VRAM during the creation process.
